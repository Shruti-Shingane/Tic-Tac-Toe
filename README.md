# 🎮 Tic Tac Toe using Python & NumPy

A simple command-line **Tic Tac Toe game** built using **Python and NumPy**.

## ✨ Features

* Two-player gameplay
* 3×3 game board
* Win and draw detection
* Invalid move handling
* NumPy array for board management

## 🛠️ Technologies

* Python
* NumPy

## 🚀 How to Run

1. Clone this repository.
2. Install NumPy:

```bash
pip install numpy
```

3. Run the program:

```bash
python tic_tac_toe.py
```
